## 확정되지 않은 것 (대본에서 단정 금지)
- **진입 시각.** 10:30(판사 2019 회고) / 11시경(Última Hora 2013, La Nación 2024 — 출처 없음) / "늦은 오전"(Última Hora 2022). 1992-12-23 당일 지면을 찾지 못했다. 대본은 "Es la mañana del 22 de diciembre de 1992."(1권 ✅) 또는 "a media mañana"로 쓰고, 시각을 꼭 쓰려면 "hacia las diez y media, según recuerda el juez" 처럼 귀속.
- **제보자.** 사법부·UNESCO 버전은 "경찰관의 아내"(이름 비공개). 워싱턴포스트 부고는 "옛 정권 경호원의 아내", 전직 경정 Ismael Aguilera 는 자기 역할을 주장(Última Hora 2022). 대본은 사법부 버전을 귀속해서 쓰고 Aguilera 는 실명으로 다루지 않는다(확인 불가 주장).
- **문서 유출 여부.** CVJ ¶52 도 "al parecer… en caso de ser cierta" 수준. 단정 금지.
- **콘도르 창립 회의 시작일(11-25).** NSA 해설뿐. 의정서는 28일 폐회만 기록.
- **브라질의 정확한 가입일.** CIA 전문으로는 1976년 6~7월 시점에 이미 6개국으로 기록. 날짜는 쓰지 않는다.
- **알마다 체포 일자·생일.** 연도만 쓴다(1937년생, 1974년 체포, 1977년 석방).
- **스트로에스네르 인도 청구가 브라질에 실제 도달했는지, 브라질의 응답.** 미주인권재판소도 확인하지 못함(¶61.119). "Brasil nunca lo entregó" 는 사실이나 "lo negó N veces" 는 근거 없음.
- **판사 단독 회고:** 첫날 라미레스 비야바 형제 카드 목격, 다음 날 아침 대법원장 경유 "공개하지 말라" 요청 → "según el juez" 귀속(이번 대조에서 새 1차 자료 없음).
- **전날 밤 언론 감시·차량 회귀:** Última Hora 편집국장 30주년 회고(S5) 단독(이번 대조에서 새 자료 없음).
- **"왜 태우지 않았나"** 가설 (b)(c) 는 우리 추론 — 가설로 명시.
