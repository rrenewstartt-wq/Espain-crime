- **제보자.** 사법부·UNESCO 버전은 "경찰관의 아내"(이름 비공개). 워싱턴포스트 부고는 "옛 정권 경호원의 아내", 전직 경정 Ismael Aguilera 는 자기 역할을 주장(Última Hora 2022). 대본은 사법부 버전을 귀속해서 쓰고 Aguilera 는 실명으로 다루지 않는다(확인 불가 주장).
- **문서 유출 여부.** CVJ ¶52 도 "al parecer… en caso de ser cierta" 수준. 단정 금지.
- **콘도르 창립 회의 시작일(11-25).** NSA 해설뿐. 의정서는 28일 폐회만 기록.
- **브라질의 정확한 가입일.** CIA 전문으로는 1976년 6~7월 시점에 이미 6개국으로 기록. 날짜는 쓰지 않는다.
- **알마다 체포 일자·생일.** 연도만 쓴다(1937년생, 1974년 체포, 1977년 석방). 본인 청구서(1차)는 '1974년 11월~1977년 9월'.
- **하베아스 데이터 접수일.** 1차 문서(청구서 cargo) = 1992-09-14. Última Hora 의 9-11 은 쓰지 않는다. 대본은 "a mediados de septiembre de 1992" 또는 "el 14 de septiembre", 경과일은 99일(또는 "unos cien días").
- **Museo de las Memorias 설립 연도.** 2002(3권·학술) / 2005(UNESCO·EFE 이관) 엇갈림 → 연도 쓰지 않음.
- **스트로에스네르 인도 청구가 브라질에 실제 도달했는지, 브라질의 응답.** 미주인권재판소도 확인하지 못함(¶61.119). "Brasil nunca lo entregó" 는 사실이나 "lo negó N veces" 는 근거 없음.
