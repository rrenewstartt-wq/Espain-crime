# /make-episode [slug | 조건]

팀을 순서대로 돌리고, **사람 확인 지점 3곳**에서 멈춘다.

| 단계 | 스킬 | 멈추는 곳 |
|---|---|---|
| 1 | `/scout` (slug 가 없을 때) | 🛑 소재 선택 |
| 2 | `/plan <slug>` | 🛑 6막 기획 확인 |
| 3 | `/write <ep>` | |
| 4 | `/package <ep>` | 🛑 제목·썸네일 확인 |
| 5 | `/produce <ep>` (장면표 → 화면 제작 → 화면 검수, 내레이션 없음) | 🛑 화면 확인 |
| 6 | `/audit <ep>` | |
| 7 | `/voice <ep>` (**맨 마지막**: 내레이션 → 재타이밍 → 최종 렌더 → 최종 검수) | 녹음은 사람이 할 수 있음 |
| 8 | `/release <ep>` | 업로드는 사람 |

사용자가 "확인 없이 끝까지"라고 하면 멈추지 않되, 위험 4 이상·사실 ❌·검사 FAIL 이 있으면 그 자리에서 멈춘다.
끝나면 단계별 결과 표와 남은 사람 할 일(본인 녹음이면 녹음, 업로드)을 보고한다. 영상 품질이 레퍼런스·경쟁 채널과 동급이 아니면(video-qa 불합격) 출고하지 않는다.
