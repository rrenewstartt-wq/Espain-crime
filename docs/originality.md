# 형식은 똑같이, 표현은 직접

이 하네스의 목표는 레퍼런스 채널 **Detrás del Enigma(@detrasdelenimga)의 형식·공식·스타일을 그대로 재현**하는 것이다.
측정할 수 있는 형식은 모두 `config/format.json` 에 수치로 고정하고, 검사 스크립트가 어긋남을 잡는다.
다만 **표현까지 복제하지는 않는다.** 표현까지 같으면 다음이 생긴다.

- 저작권 침해(대본 문장, 썸네일 이미지, 그래픽은 저작물)
- 사칭 신고(채널명·로고·대표색이 같으면 시청자가 같은 채널로 착각)
- YouTube 파트너 프로그램의 "재사용·반복 콘텐츠" 판정 → 수익 창출 제한
- 레퍼런스 시청자도 알아챈다: Cicada 3301 영상 댓글 16개가 "LEMMiNO 영상을 번역했다"고 지적했다(`docs/benchmark-report.md`)

## 무엇이 같고 무엇이 다른가

| 똑같이 가져온다 (형식, `config/format.json`) | 가져오지 않는다 (표현) |
|---|---|
| 제목 구조 `[훅] \| [고유명사]`, 길이 50~70자, 훅 종류별 우선순위 | 그 채널의 제목 문장 |
| 러닝타임 24~29분, 말 속도 분당 168단어, 현재형 내레이션 | 그 채널의 대본 문장·자막 |
| 도입 공식(날짜 장면 → 전환 → 질문 3개 → 연결 문장)과 시점 | 말버릇 "y eso lo cambia todo", 엔딩 문형 "la pregunta de verdad no es…" (`banned.reference_catchphrases`) |
| 본문 6막 구조, 중반 되돌아오기, 엔딩(현재 → 교훈 → 질문) | 같은 사건을 그 채널 영상을 보고 다시 쓰기 |
| 영상 안 인사·구독 요청 없음 | |
| 썸네일 문법(어두운 단색 톤 + 중앙 피사체 + 1~4단어 발광 대문자 + 콜라주) | **빨간 단색**(채널 정체성), 썸네일 이미지·구도 그대로 |
| 설명란 구조(장면 한 줄 → 요지 → 연결 문장 → 구독 줄 → 💬 질문) | 설명란 문장, 구독 문구 "SUSCRÍBETE para más historias como esta" |
| 태그 구조(고유명사 변형 + 분야 + 공통 2개 + 채널명 2표기) | 채널명·로고 |
| 토요일 16시(멕시코시티) 주 1회 | |

## 규칙
1. **대본은 1차 자료로 쓴다.** 판결문, 당시 보도, 공식 보고서, 당사자 인터뷰. 레퍼런스 영상은 형식 분석에만 쓴다.
   레퍼런스가 이미 다룬 사건은 `scripts/topics.py check` 가 경고한다. 다룰 수는 있지만 **다른 관점**이 있어야 하고(`episode-planner` 가 기록), 그 영상은 대본 작성 중에 보지 않는다.
2. **기계 검사:** `scripts/check_originality.py` 가 우리 대본과 레퍼런스 자막 25편을 비교한다. 8단어 이상 연속 일치, 또는 5-gram 겹침 1% 초과면 불합격(레퍼런스 자막끼리의 기준선이 0.2~1.6%다).
3. **레퍼런스 원자료**(`data/benchmark/raw/`: 자막·썸네일·설명란)는 분석용으로만 쓰고 **커밋하지 않는다**(`.gitignore`). 커밋하는 것은 측정 수치(`summary.json`: 영상 ID·제목과 수치)와 썸네일 유형 분류(`thumbnails.json`)뿐이다. 대본 문장·설명란·썸네일 이미지는 들어가지 않는다.
4. **강조색과 채널명은 사람이 정한다.** `config/format.json → thumbnail.accent`(청록 `#2EC4B6`로 결정), `config/channel.json → own_channel`. 레퍼런스의 빨강 계열과 Anatomía 의 앰버 계열은 `forbidden_accents` 로 막혀 있다.
5. **실존 인물:** 확정 판결이 없는 사람을 범인처럼 쓰지 않는다. 생존 피해자·미성년자는 실명 대신 이니셜이나 역할로, 썸네일에서는 눈을 가린다.
