## 2. Anatomía de un Hackeo: "다크 인포그래픽 + 3D 재연"

## 3. 우리 채널 ARCHIVO OSCURO 의 화면 규칙

형식 기준은 레퍼런스(Detrás del Enigma)다. 아래는 레퍼런스의 화면 문법을 따르되 표현은 새로 만든 것.

| 요소 | 규칙 | 레퍼런스와 같은 점 / 다른 점 |
|---|---|---|
| 도입부 리듬 | **첫 2분은 컷 길이 1초 안팎, 분당 25컷 이상**. 연속 패럴랙스 장면은 컷 대신 카메라 움직임으로 리듬을 만든다 | 같음 |
| 첫 화면 | 검은 화면 위 날짜 카드 또는 장면 위 날짜 카드로 시작. 인사·로고 없음 | 같음 |
| 날짜 카드 | 에피소드마다 사건에 맞는 서체(타자기·필기·스텐실) + 등장 애니메이션. 날짜는 강조색 | 문법은 같고, **강조색과 서체 세트는 우리 것** |
| 화면 소재 | 2.5D 패럴랙스 콜라주(1차 자료 사진·문서), 지도, 자료 영상, 재연 이미지 | 같음. 재연은 라이선스·표시 규칙 적용 |
| 재연·실제 구분 | 재연은 "RECREACIÓN", 실제 자료는 출처 라벨 | Anatomía 방식을 채택(레퍼런스는 확인 못 함). 사실 다큐 신뢰도에 유리 |
| 지도 | 옛 지도·위성 질감 위 강조색 경로 + 지명 | 같음 |
| 숫자 카드 | 큰 숫자 + 단위 + 카운터 애니메이션 | Anatomía 방식 |
| 이름 자막 | 굵은 대문자, 하단 좌측 | 같음 |
| 색 | 장면별 자연스러운 색보정 + 강조색은 글자·선·강조 박스에만 | 같음(본편은 단색 톤 아님) |
| 전환 | 연기·빛 번짐, 휩 팬, 막 전환에만 짧은 암전 | 같음 |

**강조색: 청록 `#2EC4B6`** (2026-11-25 결정). 레퍼런스 빨강도, Anatomía 앰버도 아닌 우리 색. 썸네일과 본편 날짜 카드·지도 경로·숫자 카운터·강조 박스에 같이 쓴다.

## 4. 결정: 재연 장면은 2.5D 사진·문서 콜라주 + 인포그래픽 (2026-11-25)

실사풍 재연 영상(영상 생성·스톡)은 쓰지 않는다. 레퍼런스 Wikileaks 편 방식(사진을 오려 겹친 패럴랙스 + 연기·빛 전환)을 기본으로, 숫자 카운터·날짜·장소 라벨·RECREACIÓN 표시는 Anatomía 방식으로. 3D 는 소품 장면에만(CPU 렌더 부담). 나중에 군중·전투처럼 사진으로 대신할 수 없는 사건이 오면 사람이 다시 결정한다.

## 5. 제작 가능성 (우리 도구 기준)
- **HyperFrames(HTML → 영상)로 충분히 만들 수 있는 것:** 날짜 카드·타이핑 애니메이션, 2.5D 패럴랙스 콜라주, 지도와 경로 애니메이션, 숫자 카운터, HUD 라벨, 이름 자막, 연기·빛 전환, 3D 소품 장면(three.js).
- **채워야 할 빈칸:** 레퍼런스의 **시네마틱 재연 영상**(실사에 가까운 군중·전투·거리 장면). 우리는 영상 생성 서비스나 라이선스 스톡 영상이 아직 없다.
  - 대안 1: 1차 자료 사진·문서의 2.5D 콜라주로 대신한다(Wikileaks 편 방식, 지금 가능).
  - 대안 2: 영상 생성 서비스(유료 API 키 필요)로 재연 컷을 만들고 "RECREACIÓN" 표시.
  - 대안 3: 라이선스 스톡 영상(유료).

## 6. 결정: 무료 소재로 최대한, 음악은 무료 라이선스 (2026-11-26)
- 2분 샘플 1차가 `video-qa` 불합격(실사 비중 약 9%, 도형 실루엣 재연, 검사기 통과용 노출 교대, 검정 들뜸·단색 톤).
- 사용자 결정: **유료 영상 생성·스톡 영상은 쓰지 않는다.** 공개 라이선스 사진·문서의 2.5D 콜라주 + 절차적 연기·빛·심도 + three.js 조명 소품으로 레퍼런스 Wikileaks 편(사진 콜라주) 수준을 목표로 한다. 시네마틱 재연 영상 비중이 큰 레퍼런스 편과의 차이는 남을 수 있음을 알고 간다.
- 인물 재연은 도형 실루엣 금지. 사진 컷아웃 또는 역광 속 자연스러운 윤곽만.
- **음악:** CC0·CC BY 라이선스 음악(크레딧 표기). 합성 드론은 보조음으로만. 유료 구독 음악은 쓰지 않는다.
