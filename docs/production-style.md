# 제작: 영상 품질 기준과 순서

**원칙 1. 영상 품질은 레퍼런스(Detrás del Enigma)와 경쟁 4채널(Criminalista Nocturno, Paulettee, Anatomía de un Hackeo, Historia Incomprendida)과 최소 동급이다.**
기준 수치는 `config/format.json → production`, 검사는 `scripts/check_video.py`, 눈으로 보는 판정은 `video-qa`.

**원칙 1-1. 영상의 스타일·포맷·구성도 동급이다.** 화질·음량만이 아니라 화면 구성(막별 화면 흐름), 편집 리듬(컷 길이), 색보정(톤), 그래픽(날짜 카드·지도·숫자 카드·이름 자막)의 수준이 레퍼런스와 같은 급이어야 한다.
레퍼런스 화면은 `scripts/benchmark_frames.py` 로 실측하고(컷 길이 분포, 밝기·채도·단색 톤 정도, 접촉 시트), 우리 영상은 `--compare` 로 같은 지표를 나란히 비교한다. 측정값은 `data/benchmark/video_style.json`, 스타일 명세는 `docs/visual-style.md`(클립 분석 후 작성).
**레퍼런스 클립 측정 전에는 화면 스타일 동급을 확인할 수 없으므로, 첫 에피소드의 `/produce` 는 클립 측정을 먼저 요구한다.**

**원칙 2. 목소리 내레이션은 맨 마지막이다.** 화면은 대본 기준 시간(분당 168단어)으로 먼저 완성하고, 모든 검수를 통과한 뒤 녹음한다. 녹음이 끝나면 음성 길이로 화면을 다시 맞추고 최종 렌더한다.

## 품질 기준 (`config/format.json → production`)

| 항목 | 기준 | 근거 |
|---|---|---|
| 해상도 | 1920×1080 이상, 24~30fps, H.264, 8 Mbps 이상 | 레퍼런스·경쟁 4채널 상위 영상 HD 100% (API 실측) |
| 음량 | -14 LUFS ±1, 트루 피크 -1 dBTP 이하, 48 kHz | YouTube 정규화 기준 (레퍼런스 음량은 미측정, 잠정) |
| 화면 전환 | 분당 8~24회, **6초 넘는 정지 화면 금지** | 잠정. 레퍼런스 클립을 확보하면 `--measure` 로 재서 갱신 |
| 암전 | 1.5초 이하 (막 전환만) | |
| 내레이션 무음 | 2.5초 넘는 무음 없음 | |
| 자막 | 화면에 굽지 않음, 업로드용 SRT 제공 | 레퍼런스·경쟁 4채널 모두 수동 자막 0% (API 실측) |

## 필수 화면 요소 (에피소드마다 전부)

| 요소 | 규칙 |
|---|---|
| 날짜 카드 | 도입과 되돌아오기(regreso)에 **같은 디자인**의 날짜·시각 카드 |
| 지도 | 장소가 처음 나올 때마다 (직접 제작) |
| 숫자 카드 | 막마다 핵심 숫자 1개 이상 |
| 문서 확대 | 1차 자료(판결문·보고서·신문)를 확대하고 해당 줄을 강조 |
| 이름 자막 | 실명 인물·기관 첫 등장 시 이름·역할 |
| 연표 | `origen`, `consecuencias` 막 |
| 정지 이미지의 움직임 | 모든 사진·문서에 줌·패닝·패럴랙스 |
| 재연 표시 | 재연·생성 이미지는 화면에 "Recreación" |
| 음악·효과음 | 배경 음악 + 전환 문장·질문 묶음·되돌아오기 지점 효과음 |
| 막 전환 | 막마다 전환 효과 |

## 레퍼런스 화면에서 확인된 것과 아직 모르는 것
- ✅ 자막·댓글·썸네일로 확인: 첫 프레임부터 내레이션(인사·로고 없음), 실존 인물·장소·문서 사용, 확정 판결 없는 인물·미성년자 눈 가림, 편집 밀도가 높음(댓글 "편집 10점", "효과가 많아 여러 명이 만드는 것 같다"), [música] 표시가 장면 전환·질문 뒤에 반복
- ❓ 프레임으로 확인해야 함: 본편 색보정(썸네일처럼 단색 톤인지), 실제 컷 길이, 그래픽 스타일, 자막 표시 여부
- **이 클라우드에서는 YouTube가 영상 다운로드를 막는다.** 화면 스타일 실측: 클립을 `data/benchmark/raw/clips/<채널핸들>__<이름>.mp4` 로 두고 `python3 scripts/benchmark_frames.py data/benchmark/raw/clips/*.mp4` → `video_style.json` + 접촉 시트. 음량·전환: 레퍼런스·경쟁 채널 클립(각 1~2편, 몇 분이면 충분)을 사람이 확보해 `data/benchmark/raw/clips/` 에 두면 `python3 scripts/check_video.py <클립> --measure` 로 같은 지표를 재고, `config/format.json → production.pacing` 의 잠정값을 실측값으로 바꾼다. 그 전까지 잠정 기준은 **완화하지 않는다.**

## 소재와 권리
- 출처·라이선스가 확인된 소재만: 공공 기록(정부·기관 아카이브), 퍼블릭 도메인, CC 라이선스, 직접 만든 지도·연표·도식·3D. 다른 유튜브·방송·다큐 화면은 쓰지 않는다.
- 모든 소재는 `shots.md` 의 출처·라이선스 칸과 설명란 `Créditos:` 에.
- 목소리는 **본인 또는 서면 허락을 받은 목소리만**(`config/channel.json → voice`). 타인 목소리를 복제하지 않는다. 녹음·생성 음성 파일은 커밋하지 않는다.

## 장면표 형식 (`episodes/<ep>/shots.md`)

| # | 막 | 대본 첫 단어 | 길이(초) | 화면 유형 | 필수 요소 | 소재 | 출처·라이선스 |
|---|---|---|---:|---|---|---|---|

화면 유형: 자료 영상 / 자료 사진 / 문서 확대 / 지도 / 연표 / 숫자 카드 / 날짜 카드 / 도식 애니메이션 / 재연 이미지.
한 행은 6초 이하가 되도록 나눈다(정지 화면 금지 기준). 출처·라이선스 칸이 비면 불합격.
